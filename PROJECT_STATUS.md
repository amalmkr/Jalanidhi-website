# 📈 Project Tracking Rules

The AI project monitor should follow these rules:

- `[x]` = Completed
- `[ ]` = Remaining
- `🟡` = In Progress
- `🟢` = Frontend/feature completed
- `🔴` = Not implemented
- Static/demo functionality must NOT be treated as production functionality.
- A route existing does NOT mean the feature is completed.
- A UI existing does NOT mean backend functionality is completed.
- localStorage functionality must NOT be treated as database functionality.
- Hard-coded data must NOT be treated as dynamic data.
- Frontend payment UI must NOT be treated as real payment processing.
- Placeholder pages must remain incomplete until actual functionality is implemented.
- Backend tasks should only become completed after actual API/database integration.
- The project progress percentage should be calculated from actual checked tasks,
  not from assumptions.
